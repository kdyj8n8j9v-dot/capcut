# Монтажная программа без Claude — план (владелец 2026-11-10)

Цель: монтаж как в CapCut, но проще (как у Apple), на iPad/iPhone, работает при закончившемся лимите Claude.
Выход — H.265 10 бит 4:2:2 (yuv422p10le, Main 4:2:2 10), 4K, CRF 12 и выше качеством, из оригиналов камеры.

## Решения владельца
- Отдельная программа в этом репозитории. Редактор «Студия 10 бит» (репозиторий `10-bit`) не трогаем: оттуда взяты
  только копии `grade.py`, `render.py`, `scripts/cloud.sh`; дальше программы друг от друга не зависят.
- Рендер — GitHub Actions (репозиторий публичный: минуты не ограничены). Сервер — позже, если не хватит скорости.
- Приложение — GitHub Pages (PWA «на экран Домой»). Код виден всем; видео, пароли и ключи — нет.
- Файлы: с устройства («Файлы», «Фото») и из MEGA («Исходники», «Для монтажа ПАК»: SFX, музыка, шрифты, переходы).
  Файлы с устройства приложение само кладёт в MEGA, оттуда их берёт сборщик. Готовое — в MEGA «10 бит» и в «Файлы».

## Устройство
```
iPad / iPhone (PWA на GitHub Pages)
  ├─ MEGA прямо из браузера (вход хранится только на устройстве): исходники, ПАК, загрузка файлов с устройства
  ├─ GitHub API (токен только на устройстве): запустить studio-worker, следить за ходом
  └─ ИИ-помощник: бесплатные модели Groq / OpenRouter (ключ только на устройстве)
GitHub Actions — .github/workflows/studio-worker.yml + worker/run.sh
  ├─ prepare: оригинал из MEGA → прокси 1080p H.264 + субтитры по словам (faster-whisper) → MEGA «10 бит/.studio»
  └─ export:  проект → render.py → H.265 10 бит 4:2:2 4K → MEGA «10 бит»
```

## Этапы
1. ✅ Облачный исполнитель на GitHub Actions (prepare, export). prepare проверен на реальном видео; export — ещё нет.
2. Приложение-основа: PWA, вход MEGA/GitHub, медиатека (устройство + MEGA), таймлайн (дорожки видео, текст,
   наложения, звук), резка/перестановка/скорость, превью, кадр и цвет, экспорт → исполнитель.
3. Субтитры: «Авто-субтитры» одной кнопкой из транскрипта, правка слов, стили и анимации по словам, шрифты владельца
   с кириллицей. В рендере — тот же HTML-движок (Chromium в Actions), поэтому превью = экспорт.
4. Наложения: картинки/видео/стикеры, анимации входа-выхода, ключевые кадры, маски (прямоугольник, круг, линия,
   кисть), режимы наложения, переходы, эффекты.
5. Звук: музыка и SFX с устройства и из «Для монтажа ПАК», громкость по ключам, приглушение под голос, обработка голоса.
6. ИИ-помощник внутри: вопрос словами → показывает, где кнопка, или делает правку в проекте.

## Что нужно от владельца (один раз)
- Settings → Secrets and variables → Actions: `MEGA_EMAIL`, `MEGA_PASSWORD`.
- Settings → Pages → Source: GitHub Actions.
- В приложении: вход MEGA и токен GitHub (fine-grained, только этот репозиторий, Actions: read & write). Не в чат.
